`main.py` draws a poster of the day's six biggest stories (APEC Trump–Xi–Putin
summit, Anthropic's $1.5T IPO, Gaza ground op, Gulf attacks, US measles
status lost, Van Gogh record sale) to `/output/entry.png`. Pillow only,
no network, deterministic.
